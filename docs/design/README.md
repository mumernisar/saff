# Design

Export the final mockups here before Stage 2:

- `system/`: the design-system page (tokens, type, components with all states)
- `screens/<flow>/<NN-screen-name>.png`: one image per screen and state, light and dark
- `flows.md`: the clickable flows (which screen leads to which)

Mockups are the source of truth for visuals. If a mockup and `PRODUCT.md` disagree, ask the owner.
